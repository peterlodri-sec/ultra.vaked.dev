ultra.vaked.dev · what ultra is

ULTRA

not a setting. a lap — run end to end, at performance, with love.
DO = reflect → improve → wire → polish → push → readme

the one rulea lap that stops before readme didn't happen

ultra is not "auto-assist on, lean, fast." That's the setting. ultra is the loop closed: every piece points at what it depends on, nothing is left half-wired, and the tree ends pushed and readme'd. A plausible branch may be ranked. Only a verified branch may be bound.

01
reflect — look back at the last lap; write the real state down.
02
improve — one real improvement. not decoration: a fix, a connection, a wiring.
03
wire end to end — every surface points at what it depends on. no orphans.
04
polish — the code, the docs, the readme. form counts.
05
push — to origin, to the right repos. both, where the site is watched twice.
06
readme — the ledger rows everything; the readme is the ledger's open face.
